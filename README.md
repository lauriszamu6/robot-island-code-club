# Astrobit

Create this product based on the specifications of the 2 documents attached and the following information: BACKGROUND DIRECTION: FLOATING ISLANDS + ROBOT WORKSHOP

Keep the established cream, teal, coral, yellow, and navy palette.

LEVEL MAP

Create a softly illustrated sky with five floating islands connected by dotted paths. Arrange the journey vertically so it works on phones and tablets.

Each island represents one level and contains:

- A small robot workshop.

- The level number and programming concept.

- Three visible game markers.

- A clear locked, available, or completed state, using labels and icons alongside color.

Use pale cream clouds, subtle lavender hills in the distance, and occasional mechanical details. Completed islands gain warm lights and a small flag. Keep the next available island easy to identify.

GAME BACKGROUND

When a child selects a game, transition into that island’s workshop.

Use a warm cream wall, teal fixtures, and a workbench along the bottom edge. Place a few tools, spare robot parts, plants, and small inventions around the sides. A rounded window shows the floating islands outside, connecting both environments.

Keep the central game area plain and spacious. Decorative objects must never overlap instructions, coding blocks, or controls. Simplify edge decorations on small screens.

PROGRESSION

After completing all three games in a level, add one decorative workshop upgrade, such as a new invention or glowing lamp. These visual upgrades are separate from parent-funded monetary rewards.

Use gentle transitions and optional subtle cloud movement. Respect reduced-motion settings. Build scenery with lightweight SVG and CSS so the backgrounds work independently of the external character API.
